# scripts/

Everything here regenerates one or more of the SVG assets used in the
top-level `README.md`. All scripts are stdlib-only Python (see
`requirements.txt`) and run automatically via the workflows in
`.github/workflows/`, but you can also run them by hand.

| Script | Regenerates | Needs a token? |
|---|---|---|
| `fetch_contributions.py` | `contributions.json` (raw data) | No — scrapes the public contribution page |
| `render_heatmap_svg.py` | `harsh-heatmap.svg` | No |
| `update_stats_and_languages.py` | `harsh-stats.svg`, `harsh-languages.svg` | No (uses the workflow's built-in `GITHUB_TOKEN` if present, otherwise falls back to unauthenticated API calls) |

`harsh-banner.svg`, `harsh-banner-light.svg`, `harsh-id-card.svg`,
`harsh-terminal.svg` and `harsh-trophies.svg` are hand-authored and static —
edit them directly if bio details change.

`harsh-snake.svg` is regenerated by `.github/workflows/snake.yml` using the
open-source [Platane/snk](https://github.com/Platane/snk) action against the
real contribution graph — no local script needed for it.

## Run locally

```bash
python scripts/fetch_contributions.py
python scripts/render_heatmap_svg.py
python scripts/update_stats_and_languages.py
```

No secrets are read outside of the optional `GITHUB_TOKEN` environment
variable, and nothing is ever printed or logged.
